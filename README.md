#### Selected work

| Project | What it is | Stack |
|---|---|---|
| [**ArtaiSpellChecker**](https://github.com/Bisratasaye12/ArtaiSpellChecker) | Context-aware Amharic spell checker: Damerau-Levenshtein candidates ranked by an n-gram language model. Team project; I wrote most of the implementation. | Python, NLP |
| [**Speech Emotion Analysis**](https://github.com/Bisratasaye12/Speech-to-Text-Sentiment-Analysis-Analyzing-Emotions-in-Spoken-Language) | Transcribes speech and classifies emotion from both the words and the audio (CNN+LSTM acoustic model fused with a text model, trained on MELD). Team project. | Python, PyTorch, Whisper |
| [**RAG agent with LangGraph**](https://github.com/Bisratasaye12/RAG-Test) | Delegating LangGraph agent over a multi-tenant Weaviate index, with tool routing and streamed `{answer, data}` responses. | TypeScript, LangChain, Weaviate, Ollama, Docker |
| [**PrepWise**](https://github.com/Bisratasaye12/My_ai_Interview_prep) | Voice mock-interview platform: a Vapi voice agent runs the interview, Gemini scores the transcript. Extended from a tutorial base with full setup docs. | Next.js 15, React 19, Firebase, Vapi, Gemini |
| [**distsql**](https://github.com/Bisratasaye12/Distributed_Database) | Distributed SQL database: SQLite storage nodes replicated with Raft, cluster join/leave, gRPC between nodes and an HTTP query API. | Go, Raft, gRPC, SQLite |
| [**HarvestLedger**](https://github.com/Bisratasaye12/my-ledger) | Inventory dashboard with search, bulk actions and accessible table UI, covered by Vitest + Testing Library. | React, TypeScript, Vite |
